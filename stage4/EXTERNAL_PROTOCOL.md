# Stage 4: frozen-model external dataset evaluation

Prepared on 1 October 2026 (Pakistan time), after the Challenge test analyses but before reading the external outcome values or computing external model performance. This is a locally locked supplementary evaluation, not public preregistration. No CAPMI material is used.

## Scope and independence

Use the openly released eICU-CRD demo v2.0.1 and the official YAIB repository's eICU sepsis demo labels. The imported static file has 896 selected unit stays; this count is a file/schema observation, not an outcome analysis. Pin the YAIB commit and input hashes. Retrieve only open-access demo data, never the credentialed full eICU dataset.

This is a different data resource from the PhysioNet Challenge and has not been used in this project's training or tuning. Real hospital names and cross-resource patient linkages are unavailable, so absence of hospital/patient overlap with Challenge A/B cannot be independently proved. Describe the result as **external dataset evaluation on a public demo**, not fully verified hospital-independent validation or prospective clinical validation.

## Labels and cohort limitations

Use the published YAIB modified `sep3_alt` target. Its eICU implementation uses continuous antibiotics as the suspicion-of-infection proxy, rather than the Challenge's paired cultures/antibiotics. The suspected-infection/SOFA windows differ from the Challenge. Do not rename these labels as an exact reconstruction of the Challenge's clinical target. Imported labels were generated by the benchmark authors; this study does not independently recompute SOFA from raw data.

The published outcome grid extends a first sepsis event six hours before and after its event time. Reconstruct the grid event as the first positive imported label time plus six hours. Require labels and times to be finite, binary, ordered and hourly. Inspect and report positive-run widths as a label-integrity diagnostic. If the supplied labels do not support that documented reconstruction, halt sensitivity reporting and explain why. Boundary censoring and operational labels require clinical review.

YAIB's selected cohort excludes short/inadequately observed stays, early onset and eICU hospitals with no labeled sepsis. This selection limits transportability and makes it inappropriate to infer clinical deployment prevalence from the demo. It is not a full eICU validation cohort.

Among imported stays, select at most one stay per `uniquepid` using the smallest SHA-256 of `20261001|stay|<stay_id>`, without inspecting outcomes. Exclude missing patient linkage, unknown/nonadult age, fewer than six complete ICU hours, first-positive label hour <=6, reconstructed onset beyond observed follow-up, and incompatible label grids. Map age `>89` to 100 to match the Challenge's age coding. Keep gender Female=0, Male=1, other/unknown missing.

## Frozen prediction input

Rebuild hourly physiological rows directly from raw public eICU lab/vital tables, rather than using already aggregated YAIB predictors. A row at ICU hour h uses only nonnegative available event offsets strictly below h*60 minutes; bin each event to floor(offset/60)+1. No future filling or interpolation. Complete-hour follow-up ends at min(floor(unitdischargeoffset/60),168); cases are scored strictly before reconstructed onset. Start evaluation at ICU hour 6, with earlier rows used only for causal feature history.

For labs, available time is max(labresultoffset, labresultrevisedoffset when present), conservatively delaying corrected results. This cannot recover a superseded earlier result. Use the last finite available value within each hourly bin, ordering ties by raw table and record identifier. Combine invasive and noninvasive pressures by event time; later events take precedence. Retain missingness when a channel is unavailable.

Map the same 34 physiological channels as the frozen model. Base Excess is used directly and Base Deficit is negated; bicarbonate uses HCO3, not Total CO2. FiO2 values >1 are divided by 100; fractional values are retained. Map total/direct bilirubin distinctly and Troponin-I only to TroponinI, never Troponin-T. Use standardized lab system units, reject unsupported unit/channel combinations, and retain an audit of mappings and exclusions. Do not change source-model feature scales based on external test scores. Source lactate/magnesium unit ambiguity must be documented, rather than silently converted to printed units inconsistent with source values.

HospAdmTime is hospitaladmitoffset/60. Apply the exact retained causal 120-feature constructor. Use the six preserved Stage 2 model files and each retained feature-index list; no model fitting, fine-tuning, patient weighting, target imputer fitting, hyperparameter selection or best-direction selection.

## External split and thresholds

Assign selected people to 30% calibration / 70% test by SHA-256 fraction of `20261001|role|<uniquepid>`. Assignment is deterministic and outcome-blind, with no stratification or reseeding. Retain all counts, even if case numbers are small. No external model training is allowed.

For every source/model pair, evaluate five rules from the unchanged Stage 3 specification: hourly, single, silence-4h, silence-6h and recurrent three-of-five. Apply unchanged natural-duration source-hourly and source-admission thresholds. Also recalibrate each rule to nominal alpha=0.10 using only nonseptic external calibration people, with standard finite rank ceil((n+1)*0.9), strict crossing and structural startup -infinity for three-of-five. First-crossing-preserving rules share a local admission threshold.

Before inspecting outcomes, retain two input variants: native numeric lab scales, and a sensitivity analysis masking Lactate and Magnesium. The source documentation's printed units for these channels are inconsistent with typical observed numeric scales. Native-scale transfer is provisional, and masking avoids choosing an unverified conversion. Report both variants without selecting one based on its performance; neither resolves source unit provenance.

This yields 6 frozen models x 3 threshold conditions x 5 policies x 2 input variants = 180 planned rows. No displayed result is used to choose a favorable policy, model, endpoint or threshold. If a calibration pool is empty, report the rule as unevaluable rather than inventing a threshold.

## Endpoints and uncertainty

Report nonseptic admissions with any emitted alert, nonseptic emissions/admission and emissions/100 scoring hours, any emission and first emission in [onset-6,onset), twelve-hour timing diagnostics and conditional lead-time summaries. Use exact two-sided 95% binomial intervals for person proportions. Report AUROC, average precision and Brier score for the imported six-hour horizon target aligned to each score-availability hour; these remain operational-label metrics, not clinically adjudicated probabilities.

Retain all six frozen-model results with denominators. Do not pool them to conceal failure. The single-stay-per-person rule supports patient-binomial uncertainty within this selected cohort; multicentre clustering, calibration uncertainty and label errors are not covered. No treatment-effect, clinical utility, official Challenge utility or published-model superiority claim is allowed.

Verify official raw-data checksums, pinned derivative hashes, source model hashes, cohort/person disjointness, causal event binning, correction offsets, unit conversions, original feature-constructor consistency, prediction determinism and rule invariants. Test boundary timing and no-future behavior before computing performance. Save protocol/config/code/input hashes and record any post-lock correction as an amendment.

The automated methodological audit is not human peer review. Prepare a clinical/statistical handoff for a real reviewer to assess label validity, timing windows, measurement/unit mapping, selection and clinical meaning. Do not invent reviewer names, signatures, approvals or completed human review. Leave existing manuscript and locked results unchanged; supplementary results require author/clinical review before incorporation.

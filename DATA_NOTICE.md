# Dataset attribution

The original pilot archive contains 3,000 unmodified, de-identified public subject files. The completed stage-two results archive contains all 40,336 released files, with the pilot files used only for exact-duplicate screening and excluded from stage-two fitting, calibration, and evaluation. The source is:

Reyna, M., Josef, C., Jeter, R., Shashikumar, S., Moody, B., Westover, M. B., Sharma, A., Nemati, S., and Clifford, G. D. (2019). **Early Prediction of Sepsis from Clinical Data: The PhysioNet/Computing in Cardiology Challenge 2019**, version 1.0.0. PhysioNet. https://doi.org/10.13026/v64v-d857

Source and access/license statement: https://physionet.org/content/challenge-2019/1.0.0/

Dataset license: **Creative Commons Attribution 4.0 International (CC BY 4.0)**, https://creativecommons.org/licenses/by/4.0/ . The creators retain attribution; no endorsement of this analysis is implied. Hospital A/B subdirectories and deterministic study partitions were selected without changing the source PSV file contents. Derived features, models, metrics, and figures were created for the current project.

Also cite the resource paper:

Reyna MA, Josef CS, Jeter R, Shashikumar SP, Westover MB, Nemati S, Clifford GD, Sharma A. **Early Prediction of Sepsis From Clinical Data: The PhysioNet/Computing in Cardiology Challenge.** Critical Care Medicine, 48(2), 210–217. https://doi.org/10.1097/CCM.0000000000004145

The dataset page additionally requests the current PhysioNet platform citation:

Pollard T, Moody BE, Lehman L, Gow B, Fernandes C, Xie C, Johnson A, Mark RG, Heldt T. **PhysioNet as a global platform for biomedical research.** Nature Health 1, 792–795 (2026). https://doi.org/10.1038/s44360-026-00096-z

No CAPMI files or findings are included. Public source data must not be confused with a newly collected clinical cohort. Institutional requirements for retrospective public-data research still need to be assessed by the eventual authors before submission; this package does not assert an ethics exemption or approval.
